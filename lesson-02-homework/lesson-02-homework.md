# Assignments

This file lists two assignments following the second lesson, one about footnotes, the other concerning citations and bibliographies. They are not required to complete before the third lesson, but can help you recall and deepen your understanding on how to use the respective features.

# Footnotes

<https://www.markdownguide.org/extended-syntax/#footnotes> explains how to create simple footnotes. These are supported by many different Markdown dialects and parsers. The Pandoc parser (which is built into Zettlr) also lets you add footnotes directly in the text: <https://pandoc.org/demo/example33/8.19-footnotes.html>

1. Use the [final version](https://github.com/Nerithi/2026-necron/blob/a24c38c6920cb799afaa12b2c009b8d01f61c86e/lesson-02-materials/lesson-02-final.md) of the file we created during the lesson and create an inline footnote at the end of the first paragraph that says "Although it must be noted that the data basis is generally fairly scarce."
2. Export to HTML, PDF and Word in turn and check that the new footnote has appeared.

# Citations & Bibliography

<https://quarto.org/docs/authoring/citations.html#sec-citations> includes a very good overview of the ways Pandoc allows you to cite literature with Markdown.^[You don't need to download or install Quarto -- it is just different software using Markdown as a basis to create and publish text. Since it also uses Markdown and Pandoc, many instructions from the User Guide will also work in Zettlr.]

1. Experiment with different versions of -@citationkey, with page numbers, in square brackets, page numbers in square brackets etc.
2. Add several citations to be cited in parentheses, with page numbers.
3. Change citation styles by choosing a different .csl file from the folder and compare the export results.
